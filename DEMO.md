# Демо-доступ к отчётам — инструкция

## Что нужно сделать на рабочем ПК (один раз)

### 1. Установить ngrok

```powershell
winget install ngrok
```

Если `winget` недоступен — скачать вручную с [ngrok.com/download](https://ngrok.com/download), распаковать `ngrok.exe` в любую папку.

### 2. Запустить dev-сервер

```powershell
cd F:\projects\reports
npm run dev
```

Дождаться сообщения `✓ Ready on http://localhost:3000`.

### 3. Запустить туннель (в отдельном окне PowerShell)

```powershell
ngrok http 3000
```

В терминале появится строка вида:

```
Forwarding   https://abc123xyz.ngrok-free.app -> http://localhost:3000
```

Эту ссылку (`https://abc123xyz.ngrok-free.app`) отправить клиенту.

---

## Что видит клиент

- Открывает ссылку в браузере — никаких установок не требуется
- Видит отчёты по прямым ссылкам вида `/r/slug`
- Авторизация не нужна для просмотра отчётов

---

## Важно

- Туннель работает **пока открыт терминал с ngrok**. Закрыл окно — ссылка перестала работать.
- URL **меняется при каждом запуске** ngrok (бесплатный план). Каждый раз нужно отправлять новую ссылку.
- Если нужен постоянный адрес — это решается переездом на VDS (отдельная задача).
